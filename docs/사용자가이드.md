## 2. 권한 체계

사용자는 3가지 권한 중 하나를 가집니다.

| 권한 | 명칭 | 접근 가능 메뉴 |
|------|------|----------------|
| ADMIN | 최고관리자 | 전체 메뉴 (공지사항, 고객관리, 인사관리, 공통코드관리) |
| MANAGER | 매니저 | 공지사항, 고객관리, 공통코드관리 |
| USER | 일반사용자 | 공지사항, 고객관리 |

> 권한이 없는 메뉴에 접근 시 공지사항 화면으로 이동됩니다.

## 3. 로그인 및 로그아웃

### 3.1 로그인

1. 브라우저에서 시스템 주소로 접속하면 자동으로 로그인 화면이 표시됩니다.
2. **아이디**와 **비밀번호**를 입력 후 **로그인** 버튼을 클릭합니다.
3. 로그인 성공 시 공지사항 화면으로 이동합니다.

**오류 상황**

| 상황 | 메시지 | 조치 |
|------|--------|------|
| 아이디/비밀번호 오류 | 아이디 또는 비밀번호가 올바르지 않습니다 | 다시 입력 |
| 비활성 계정 | 비활성화된 계정입니다 | 관리자에게 문의 |
| 비밀번호 초기화됨 | 비밀번호 재설정 화면으로 이동 | [4.1 참고](#41-비밀번호-초기화-후-재설정) |

### 3.2 로그아웃

- 화면 우측 상단 메뉴에서 **로그아웃**을 클릭합니다.
- 로그아웃 시 로그인 화면으로 이동하며, 접속 기록이 저장됩니다.

## 4. 비밀번호 관리

### 4.1 비밀번호 초기화 후 재설정

관리자가 비밀번호를 초기화한 경우, 로그인 시 자동으로 비밀번호 재설정 화면이 나타납니다.

1. 새 비밀번호를 입력합니다.
2. 새 비밀번호를 한 번 더 입력합니다.
3. **변경** 버튼을 클릭합니다.

**초기 비밀번호**: `아이디 + 1234!` (예: 아이디가 `hong`이면 `hong1234!`)

### 4.2 내 비밀번호 변경

로그인 후 언제든지 비밀번호를 변경할 수 있습니다.

1. 우측 상단 프로필 또는 내 정보 메뉴에서 **비밀번호 변경**을 선택합니다.
2. **현재 비밀번호**를 입력합니다.
3. **새 비밀번호**와 **새 비밀번호 확인**을 입력합니다.
4. **변경** 버튼을 클릭합니다.

**비밀번호 규칙**

- 8자 이상
- 영문, 숫자, 특수문자를 모두 포함해야 합니다.
- 예시: `MyPass1!`, `Work2026@`

## 5. 공지사항

로그인 후 기본으로 표시되는 화면입니다.

### 5.1 공지사항 목록

- 전체 공지사항 목록이 최신순으로 표시됩니다.
- 제목을 클릭하면 상세 내용을 확인할 수 있습니다.

### 5.2 공지사항 작성

모든 로그인 사용자가 공지사항을 작성할 수 있습니다.

1. **작성** 버튼을 클릭합니다.
2. 제목과 내용을 입력합니다.
3. **저장** 버튼을 클릭합니다.

### 5.3 공지사항 수정/삭제

- **수정**: 본인이 작성한 공지사항만 수정 가능합니다.
- **삭제**: 본인 작성 글 또는 ADMIN은 모든 글 삭제 가능합니다.

## 6. 고객관리

고객 정보를 등록하고 관리하는 메뉴입니다.

### 6.1 개인고객관리

개인 고객 정보를 조회, 등록, 수정, 삭제합니다.

**검색**
- 고객명, 연락처, 상태 등 조건으로 검색이 가능합니다.
- 검색 조건 입력 후 **조회** 버튼을 클릭합니다.

**등록**
1. **등록** 버튼을 클릭합니다.
2. 고객 정보(이름, 연락처, 주소 등)를 입력합니다.
3. **저장** 버튼을 클릭합니다.

**수정**
1. 목록에서 수정할 고객을 선택합니다.
2. 정보를 수정 후 **저장** 버튼을 클릭합니다.

**삭제**
1. 목록에서 삭제할 고객을 선택합니다.
2. **삭제** 버튼을 클릭합니다.

### 6.2 협력점 고객관리

협력점(파트너사) 고객 정보를 관리합니다. 조작 방법은 개인고객관리와 동일합니다.

## 7. 인사관리 (관리자 전용)

**ADMIN(최고관리자)만 접근 가능합니다.**

직원 계정을 생성하고 권한을 관리합니다.

### 7.1 직원 목록 조회

- 아이디, 이름, 부서, 권한, 사용여부로 검색할 수 있습니다.
- **조회** 버튼을 클릭하면 결과가 표시됩니다.

### 7.2 직원 등록

1. **등록** 버튼을 클릭합니다.
2. 다음 정보를 입력합니다:

| 항목 | 필수 | 설명 |
|------|------|------|
| 아이디 | 필수 | 로그인에 사용할 ID (중복 불가) |
| 비밀번호 | 필수 | 8자 이상, 영문+숫자+특수문자 포함 |
| 이름 | 필수 | 직원 이름 |
| 부서 | 선택 | 소속 부서 |
| 권한 | 필수 | ADMIN / MANAGER / USER |
| 사용여부 | 필수 | Y(활성) / N(비활성) |

3. **저장** 버튼을 클릭합니다.

### 7.3 직원 수정

1. 목록에서 수정할 직원을 선택합니다.
2. 정보를 수정합니다. (비밀번호 입력 시에만 변경됩니다)
3. **저장** 버튼을 클릭합니다.

### 7.4 비밀번호 초기화

직원이 비밀번호를 잊은 경우 관리자가 초기화할 수 있습니다.

1. 목록에서 해당 직원을 선택합니다.
2. **비밀번호 초기화** 버튼을 클릭합니다.
3. 초기화된 비밀번호: `아이디 + 1234!`
4. 해당 직원은 다음 로그인 시 비밀번호를 반드시 변경해야 합니다.

### 7.5 직원 삭제

1. 목록에서 삭제할 직원을 선택합니다.
2. **삭제** 버튼을 클릭합니다.

> 주의: 삭제 시 해당 계정의 로그인 이력도 함께 삭제됩니다.

## 8. 공통코드관리 (관리자/매니저)

**ADMIN 및 MANAGER만 접근 가능합니다.**

시스템에서 사용하는 드롭다운 선택 항목(코드 값)을 관리합니다.

### 8.1 그룹코드 관리

여러 코드를 묶는 그룹 단위를 관리합니다.

- **조회**: 그룹명으로 검색 가능
- **등록**: 그룹코드, 그룹명, 사용여부 입력 후 저장
- **수정**: 그룹명, 사용여부, 비고 수정 가능
- **삭제**: 하위 상세코드가 없는 경우에만 삭제 가능

### 8.2 상세코드 관리

그룹코드 내의 개별 코드 항목을 관리합니다.

- **조회**: 그룹코드 선택 후 해당 상세코드 목록 표시
- **등록**: 코드값, 코드명, 정렬순서, 사용여부 입력 후 저장
- **수정**: 코드명, 정렬순서, 사용여부 수정 가능
- **삭제**: 해당 코드 항목 삭제

> 사용여부를 'N'으로 설정한 코드는 드롭다운 목록에 표시되지 않습니다.

## 9. 세션 관리 안내

### 9.1 자동 로그아웃

보안을 위해 로그인 후 **1시간**이 지나면 자동으로 로그아웃됩니다.

- 세션 만료 시 "세션이 만료되었습니다. 다시 로그인해주세요." 메시지가 표시됩니다.
- 확인 클릭 후 로그인 화면으로 이동합니다.

### 9.2 다중 탭 사용

- 여러 탭에서 시스템을 사용하는 경우, 한 탭에서 로그아웃하면 모든 탭이 로그아웃됩니다.

### 9.3 재로그인

자동 로그아웃 후에는 작업 중이던 내용을 저장하고 다시 로그인하세요.

## 부록. 자주 묻는 질문 (FAQ)

**Q. 비밀번호를 잊어버렸습니다.**
A. 관리자에게 비밀번호 초기화를 요청하세요. 초기화 후 `아이디 + 1234!`로 로그인하면 새 비밀번호로 변경할 수 있습니다.

**Q. 메뉴가 보이지 않습니다.**
A. 권한에 따라 접근 가능한 메뉴가 다릅니다. 필요한 권한이 있다면 관리자에게 권한 변경을 요청하세요.

**Q. 로그인이 안 됩니다.**
A. 계정이 비활성(USE_YN=N) 상태일 수 있습니다. 관리자에게 계정 활성화를 요청하세요.

**Q. 작업 중 갑자기 로그인 화면으로 이동합니다.**
A. 세션(1시간)이 만료된 것입니다. 다시 로그인 후 작업을 계속하세요.
